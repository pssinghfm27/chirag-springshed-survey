# CHIRAG Springshed Survey

A free Android app for hydrogeological field surveys, built for the
Central Himalayan Rural Action Group (CHIRAG) and shared openly for
any NGO doing springshed restoration work in the Indian Himalayan region.

## What it does

Captures the 11-parameter hydrogeological survey for any spring,
automatically reading 7 of the 11 parameters from the phone's GPS
and orientation sensors. Computes the probable recharge zone for
each spring on-device. Exports to CSV and Excel. Works fully offline.

## Who built it

Developed during a summer internship at CHIRAG, Uttarakhand
